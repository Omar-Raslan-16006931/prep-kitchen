# Prep Kitchen

Personal meal prep app: groceries with prices and macros, recipes with cost per serving, a weekly plan, a shopping list, and daily targets.

Next.js + Tailwind + Kokonut UI + Supabase (schema `mealprep`).

Env vars: `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`.
